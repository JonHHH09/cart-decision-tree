# Support

- Use GitHub Discussions for usage and design questions when enabled.
- Use the issue templates for reproducible bugs and scoped improvements.
- Use private vulnerability reporting for security concerns; see `SECURITY.md`.

This community project provides best-effort support for the latest release. Include the release tag, Java/Docker version, operating system, sanitized logs, and a minimal reproduction. Remove credentials, personal data, absolute private paths, and proprietary datasets before posting.
